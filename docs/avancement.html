Pages du PDF

Pour un registre relevé, la page du registre citée par le répertoire donne la page du PDF à ouvrir. Ailleurs, le PDF s'ouvre à sa première page.

État civil fédéral (SB 267) : sans relevé, la page du PDF est déduite de la page du registre (« ≈ », page + 3), sans avoir été vérifiée ; vers la fin du registre, elle peut être 1 à 4 pages plus loin. Les registres qui dépassent 1899 (naissances), 1929 (mariages) ou 1959 (décès) ne sont publiés que jusqu'à cette année-là, sans répertoire : pas de page déduite.

Aperçu : les PDF pèsent souvent plusieurs centaines de Mo. Avec le script d'aperçu (Tampermonkey, dans Chrome ou Firefox), les liens « PDF p. » n'en chargent que la page demandée.

Aperçu : le script d'aperçu est installé : les liens « PDF p. » n'affichent que la page demandée, sans télécharger le PDF entier.
